# GiMun Android 정식 배포

이 저장소는 [GiMun-Android](https://github.com/kyengilam-coder/GiMun-Android)의
Android 정식 APK 전용 배포처입니다.

- 설치 파일: [최신 릴리스](https://github.com/kyengilam-coder/GiMun-Android-release/releases/latest)
- 모든 APK는 하나의 영구 배포키로 서명합니다.
- 소스 저장소에 새 `v*` 태그가 등록되면 자동 배포 작업이 최신 버전을 확인해 게시합니다.

이전에 배포된 임시 디버그 APK는 서명이 매번 달랐습니다. 첫 정식 APK는 기존 앱을 한 번
삭제한 뒤 설치해야 하며, 이후 버전부터는 앱 안의 업데이트 안내로 설치할 수 있습니다.
