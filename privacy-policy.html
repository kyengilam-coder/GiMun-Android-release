기문포국 개인정보처리방침

시행일 2026-09-23 · 앱 이름 기문포국 · 패키지 com.gimun.poguk

이 앱은 개인정보를 수집하지도, 저장하지도, 외부로 보내지도 않습니다. 계정도 로그인도 없고, 광고나 분석 도구를 넣지 않았습니다. 포국 계산과 방위 표시는 모두 기기 안에서 이루어집니다.

앱이 쓰는 권한과 그 이유

권한쓰는 곳처리 방식
카메라 擇方 방위판의 AR 겹쳐 보기 화면에 미리보기만 겹쳐 보입니다. 사진·영상을 저장하거나 보내지 않습니다. 거부해도 방위판은 그대로 씁니다.
대략적 위치 眞北(진북) 보정을 켤 때의 편각 계산 좌표를 안드로이드의 GeomagneticField 에 넣어 편각만 구하고 곧 버립니다. 저장·전송하지 않습니다. 거부하면 자북을 씁니다.
인터넷 아래 ‘망 사용’ 참조 Play 에서 받은 앱은 이 권한으로 아무 곳에도 접속하지 않습니다.

방향·기울기 표시에는 회전 벡터·자기장 센서 값을 읽습니다. 센서 값은 화면에 보여 주기 위해서만 쓰이며 기기 밖으로 나가지 않습니다.

저장되는 것

  • 입력한 날짜·시각과 포국 결과는 앱을 닫으면 사라지는 임시 저장소(sessionStorage)에만 있습니다.
  • 앱 데이터 백업을 꺼 두었으므로 클라우드 백업이나 adb backup 으로 앱 데이터가 밖으로 나가지 않습니다.
  • 계산에 쓰는 절기·음력 자료와 설명서는 모두 앱 안에 들어 있습니다. 내려받지 않습니다.

망 사용

  • Play 에서 받은 앱은 어떤 서버에도 접속하지 않습니다. 화면과 자료를 전부 앱 안에서 읽습니다.
  • GitHub 에서 직접 받은 앱(같은 앱의 다른 배포본)은 새 버전이 있는지 GitHub 의 공개 릴리스 정보를 확인하고, 사용자가 동의할 때만 새 설치 파일을 내려받습니다. 이 요청에는 개인정보를 담지 않습니다. 다만 인터넷 접속이므로 GitHub 서버에는 접속 기록(IP 주소 등)이 남을 수 있으며, 이는 GitHub 의 처리 방침에 따릅니다.

제3자 제공·광고·분석

개인정보를 제3자에게 제공하거나 판매하지 않습니다. 광고 식별자를 쓰지 않고, 분석·추적 도구를 넣지 않았습니다. 앱에 포함된 외부 라이브러리는 없습니다.

아동

아동을 대상으로 만든 앱이 아니며, 아동으로부터 개인정보를 수집하지 않습니다.

이용자의 권리

앱이 개인정보를 모으지 않으므로 열람·정정·삭제를 요청할 대상 자료가 없습니다. 카메라·위치 권한은 안드로이드 설정에서 언제든 끌 수 있고, 꺼도 앱의 계산 기능은 그대로 씁니다.
